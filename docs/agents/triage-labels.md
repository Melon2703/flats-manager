# Triage labels

Use the tracker label corresponding to each canonical role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate the issue. |
| needs-info | needs-info | Waiting for more information. |
| ready-for-agent | ready-for-agent | Specified for agent work, subject to blockers. |
| ready-for-human | ready-for-human | Requires human implementation. |
| wontfix | wontfix | Will not be actioned. |
